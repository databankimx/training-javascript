# Homework: command panel

Build a small command panel with one text input and one button. The command should run when the user clicks the button or presses Enter in the input. Use one named `runCommand` function for both events and keep a count of how many times it has run.

```javascript
function runCommand() {
  // Read the command, increment the count, and update the output.
}
```

```text
Command ran 1 time: Archive
```

## Try it Yourself

Add a `blur` handler that trims the command before it runs. Then add a second button that resets the count. Make sure pressing Enter does not submit a form or trigger the command twice.
