# Homework: value inspector

Use getter and setter methods to update a profile. When the button is clicked, set the name to `Grace`, set the region to `West`, then read both values back and display them.

```javascript
$("#name").val("Grace");
$("#region").val("West");
// Read both values for the report.
```

```text
Updated name: Grace
Updated region: West
```
