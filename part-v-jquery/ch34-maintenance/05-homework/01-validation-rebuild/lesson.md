# Rebuild a validation message

The starter page has an email field and a Save button. Add jQuery validation that rejects a value without `@`, adds an `invalid` class to the field, writes a helpful message, and focuses the first invalid field. A valid value should remove the class and report success.

```javascript
$("#save").on("click", function () {
	// Add validation and feedback here.
});
```

```text
Enter an email address.
```
