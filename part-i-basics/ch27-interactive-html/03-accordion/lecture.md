# 22 · Accessible accordions  -  optional lecture

## Before class

An accordion should open and close sections. Ideally, it should also work for someone using a keyboard, which is a perfectly ordinary expectation for an interface.

Read Lesson and predict the sample output. Bring one question about 22 · accessible accordions.

## Instructor demonstration

Run the original example, then ask for an explanation of the result. Work through Try it yourself together, including one awkward input. Leave enough room for a prediction before revealing the fix; otherwise we’ve demonstrated typing rather than reasoning.

## Pair discussion

Add a third section in HTML without changing JavaScript. Compare native details with a custom button/panel accordion and identify which accessibility behavior would need to be implemented.

## Debrief

Ask for an explanation of the data flow, then invite the group to find an assumption worth testing. Keep the discussion aimed at the code. A mistaken prediction gives us something useful to investigate; it is not a personality assessment.
