# 02 · Values, bindings, and coercion  -  optional lecture

## Before class

Imagine that a form gives us the value "5" and we need to add two. This seems like a modest request. JavaScript would like us to be a little more specific about what we mean by “add.”

Read Lesson and predict the sample output. Bring one question about 02 · values, bindings, and coercion.

## Instructor demonstration

Run the original example, then ask for an explanation of the result. Work through Try it yourself together, including one awkward input. Leave enough room for a prediction before revealing the fix; otherwise we’ve demonstrated typing rather than reasoning.

## Pair discussion

Write a conversion that accepts a numeric string and rejects a value that is not a finite number. Try "12.5", "apple", and "Infinity". Decide how to treat an empty string.

## Debrief

Ask for an explanation of the data flow, then invite the group to find an assumption worth testing. Keep the discussion aimed at the code. A mistaken prediction gives us something useful to investigate; it is not a personality assessment.
