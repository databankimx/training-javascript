# Hello with variables  -  optional lecture

## Before class

Have learners run the first Hello step before introducing declarations. The point is to add names to a working example, not to make terminology the first obstacle.

## Instructor demonstration

Run the three declarations and ask which values can be changed. Show a reassignment to `greeting`, then attempt one to `name`. Contrast the useful modern defaults with `var` as a legacy form learners will still encounter.

## Pair discussion

Ask pairs to replace `var punctuation` with `const punctuation`, then explain why the output is unchanged and the intent is clearer.

## Debrief

Keep scope and reassignment separate in the explanation. `const` fixes the binding, not necessarily the contents of an object or array; save that wrinkle for the collection lessons if the room is already full of wrinkles.
