# S23 · Game of Life and simultaneous updates  -  optional lecture

## Before class

Every cell decides its next state from the same current generation. Updating the board as we go gives later cells privileged information, which seems unfair even by cellular standards.

Read Lesson and predict the sample output. Bring one question about s23 · game of life and simultaneous updates.

## Instructor demonstration

Run the original example, then ask for an explanation of the result. Work through Try it yourself together, including one awkward input. Leave enough room for a prediction before revealing the fix; otherwise we’ve demonstrated typing rather than reasoning.

## Pair discussion

Advance two generations and compare with the initial grid. Add a still-life 2×2 block inside a larger grid.

## Debrief

Ask for an explanation of the data flow, then invite the group to find an assumption worth testing. Keep the discussion aimed at the code. A mistaken prediction gives us something useful to investigate; it is not a personality assessment.
